Evidence over hype

Fail visibly. Recover deliberately.

Verity-1 is designed to preserve uncertainty instead of converting missing evidence into a success-shaped response.

✓Schema contracts reject unexpected fields and invalid data.
✓Source records remain separate from generated summaries.
✓The deterministic CI path verifies retry routing and artifact generation without an external key.
